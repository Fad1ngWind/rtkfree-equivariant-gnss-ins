# Security and responsible disclosure

Do not put credentials, access tokens, private keys, personal data, precise private trajectories, private chat exports, or restricted datasets in issues, commits, patches, or run logs.

There is no public vulnerability-reporting channel yet. Until one is approved, report concerns privately to the project owner through the existing trusted channel and provide only the minimum information needed to reproduce the issue. Never attach restricted data.

The repository's release check is a defense-in-depth measure, not a substitute for human review or a dedicated secret scanner.
