# INC-P2-20260825-002 — mixed-calibration data-minimization note

Date: 2026-08-25 (Asia/Shanghai)

Controller-reviewed classification: ordinary data-minimization boundary note; not an information-security incident. The identifier is retained only for audit continuity.

## Trigger and scope

During a field-contract inspection, the approved official file was found to contain static transforms for devices beyond the required GNSS-antenna-to-IMU calibration.

Those static device extrinsics are not a reference trajectory, error, or label. They were not used and did not affect route roles, source choice, receiver choice, diagnostics, thresholds, model design, or any experiment.

## Data minimization

- Select only the named GNSS-antenna-to-IMU transform into a small repository-external derived calibration record.
- Keep the original official source only in repository-external staging for provenance; remove its copied instance from the deployable session after the selected record and manifest are verified.
- Future preparation performs the same positive-key selection and never promotes the complete mixed file.
- Other static-device transforms remain outside the deployable interface because they are unnecessary, not because they are sealed reference information.

This note does not alter Medium's development role or Deep's independently frozen primary holdout, and it is not Phase 2 acceptance.
