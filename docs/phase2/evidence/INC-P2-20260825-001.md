Classification: controlled sealed-reference procedure deviation; no evidence of experimental contamination and no formal evaluation occurred.

## Trigger and affected boundary

A general web search intended to locate an official repository version and deployable file names returned a search-result summary from an official repository path category reserved for ground-truth visualization data. No numerical value, search-result text, screenshot, query, or content-bearing URL is retained here.

Independent review found no evidence that the summary influenced an experimental choice. The event therefore does not itself invalidate a route or result. A route becomes invalid for formal evaluation only if reference information actually influences development, comparison, tuning, or another prohibited choice.

Before the incident:

1. `UrbanNav-HK-Medium-Urban-1` had already been selected as the minimal development start using official deployable metadata.
2. The known faulty F9P observation file had already been excluded using the official issue record and observation availability, without reference-error information.
3. The WSL-native data, run, and root-only empty sealed-reference roots had already been selected and permission-checked.
4. The GNSS/IMU/calibration download allowlist had already been accepted; ground truth, reference, SPAN/INSPVAX, ROS bag, and unrelated sensor products were already excluded.

At and after the incident:

1. The exposure occurred only through a general search-result summary.
2. No reference file was downloaded or opened directly.
3. No reference error, aggregate, comparison, or metric was computed.
4. No exposed content was used for route choice, split choice, preprocessing, WLS design, weighting, thresholding, tuning, training, model selection, seed selection, validation, or claims.
5. Search and repository modification stopped immediately, the controller was notified, and the worktree remained clean.
6. The user confirmed that they had not opened or downloaded UrbanNav Ground Truth, reference, SPAN, or INSPVAX content.

- After the complete method freeze, either TST-lineage route may support a supplemental in-domain or historical-compatibility evaluation. Any paper use of its high-precision result must disclose this search-summary procedure deviation and the absence of evidence that it influenced development.
- No high-precision reference is downloaded in Phase 2; the root-only sealed-reference directory remains empty.
- Data freezing now prioritizes pinned first-party metadata and pre-listed official acquisition entries. High-precision reference content is not opened or used; ordinary official-metadata and literature searches remain permitted when they do not expose or use reference results.
