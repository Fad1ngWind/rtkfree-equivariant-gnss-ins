# Contributing

This project is not accepting external contributions during Phase 0.

Before any future contribution:

1. Read `docs/governance/DATA_AND_INFORMATION_POLICY.md`.
2. Work only in the canonical source tree and never copy legacy implementation code.
3. Keep formal data, references, weights, run outputs, private conversations, and secrets outside Git.
4. Add provenance and tests for every behavioral change.
5. Run `bash scripts/healthcheck.sh` and the staged public-release check.
6. Do not publish or open a pull request until the controller approves the current phase and license.

Scientific-method changes require an experiment-registration update before execution. Any change after a sealed final evaluation invalidates that route as an untouched final test route.

Public-facing README and repository presentation changes must follow `docs/governance/PUBLIC_REPOSITORY_STYLE.md`.
